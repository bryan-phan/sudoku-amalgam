# Data Layout

- `images/`: input Sudoku photos and sample images.
- `images/batch_drop/phone_photos/`: the 28-photo HEIC evaluation batch.
- `images/batch_drop/digital_screenshots/`: paste/save digital Sudoku screenshots here.
- `exports/`: generated cell crops and other image exports.
- `metrics/`: generated prediction, evaluation, and labeling JSON/text files.
